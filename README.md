# 🤟 ЖестПринт — конструктор принтов на жестовой нотации

Веб-приложение для создания дизайна одежды с принтами в виде **дактильных жестов** (русская жестовая азбука). Пользователь вводит текст — система автоматически преобразует его в последовательность жестов и размещает на макете одежды.

## 📖 О проекте
ЖестПринт - решает задачу **автоматизированного проектирования принтов на текстильных изделиях** с использованием **жестовой нотации**. Оно объединяет два направления:

- 🎨 **Конструкторы принтов** (как Vsemayki, Printful) — редактор макета, работа со слоями, экспорт
- 🤟 **Системы жестовой коммуникации** (как Hand Talk, sign.mt) — преобразование текста в жесты

Ни одно из существующих решений **не поддерживает** визуализацию жестов на текстиле. **ЖестПринт** закрывает эту нишу.

---

## ✨ Возможности

- ✍️ **Транскрипция текста** — ввод фразы до 15 символов, автоматическое преобразование в дактильные жесты
- 👕 **6 типов одежды** — футболка, лонгслив, худи, свитшот, майка, шоппер
- 🎨 **Выбор цвета** — 5 предустановленных цветов ткани
- 🖼️ **Свой мокап** — загрузка PNG-изображений на макет
- 🖱️ **Редактор Canvas** — перетаскивание, масштабирование, поворот, работа со слоями
- ↶↷ **Undo / Redo** — история из 40 действий (`Ctrl+Z` / `Ctrl+Shift+Z`)
- 💾 **Сохранение макетов** — в `localStorage` (до 30 дизайнов)
- 📥 **Экспорт PNG** — высокое разрешение, прозрачный фон для печати
- 📱 **Адаптивность** — работает на desktop, tablet, mobile

## 🚀 Быстрый старт

### 1. Клонирование

```bash
git clone https://github.com/DiabloDeLaMisa/ZhestPrint.git
cd zhestprint
```

### 2. Запуск

Просто открой `index.html` в браузере.

**⚠️ Важно:** запускай **через локальный сервер**, а не двойным кликом (`file://`), иначе браузер заблокирует загрузку мокапов.

**Способ 1 — Live Server (VS Code):**
1. Установи расширение **Live Server**
2. Правой кнопкой на `index.html` → **Open with Live Server**

**Способ 2 — Python:**
```bash
python -m http.server 8000
```
Открой: http://localhost:8000

**Способ 3 — Node.js:**
```bash
npx serve
```

## 🎮 Использование

### Главная
- **«Создать свой принт»** — открывает редактор
- **«Каталог»** — готовые идеи дизайнов

### Редактор
1. **Введи текст** (до 15 символов, только русские буквы)
2. **Нажми «Сгенерировать жесты»** — жесты появятся в области груди
3. **Выбери тип одежды** и **цвет**
4. **Перетаскивай, масштабируй, поворачивай** жесты мышкой
5. **Экспортируй PNG** для печати

### Горячие клавиши

| Клавиши | Действие |
|---------|----------|
| `Ctrl + Z` | Отменить |
| `Ctrl + Shift + Z` / `Ctrl + Y` | Повторить |
| `Ctrl + S` | Сохранить дизайн |
| `Delete` | Удалить выбранный объект |

## 🔧 Настройка

### Как подогнать область печати под свой мокап

Открой `index.html`, найди блок **`PRINT_AREAS`**:

```js
const PRINT_AREAS = {
  tshirt:     { left: 175, top: 200, width: 150, height: 200 },
  longsleeve: { left: 175, top: 195, width: 150, height: 210 },
  hoodie:     { left: 180, top: 230, width: 140, height: 180 },
  sweatshirt: { left: 175, top: 210, width: 150, height: 200 },
  tank:       { left: 185, top: 195, width: 130, height: 220 },
  tote:       { left: 160, top: 230, width: 180, height: 200 }
};
```

Canvas — **500 × 600**. Подбирай координаты так, чтобы рамка попала на грудь.

### Замена мокапов

1. Положи свои PNG (прозрачный фон, минимум 1000×1000) в `mockups/`
2. Назови файлы точно как в `GARMENT_IMAGES`:

```js
const GARMENT_IMAGES = {
  tshirt:     'mockups/tshirt.png',
  longsleeve: 'mockups/longsleeve.png',
  hoodie:     'mockups/hoodie.png',
  sweatshirt: 'mockups/sweatshirt.png',
  tank:       'mockups/tank.png',
  tote:       'mockups/tote.png'
};
```

## ⚠️ Ограничения

- **Только дактиль** (побуквенно), а не полноценный РЖЯ
- **Русский алфавит** — 33 буквы + пробел
- **До 15 символов** в одной фразе
- **Статическая визуализация** — без анимации
- Жесты — **стилизованные пиктограммы**, не точные дактилемы
